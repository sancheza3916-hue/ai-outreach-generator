# AI Marketing Outreach Generator

A Node.js automation tool that uses the OpenAI API to generate 
personalized marketing outreach messages for small businesses at scale.

## What It Does
Takes structured lead data from a CSV file and converts it into 
niche-specific, AI-generated outreach copy tailored for customer 
acquisition and engagement — eliminating hours of manual copywriting.

## Tech Stack
- Node.js
- OpenAI API
- CSV parsing
- Prompt engineering

## How It Works
1. Load your CSV file with lead data (business name, niche, target audience)
2. The tool processes each row and builds a custom prompt
3. OpenAI generates personalized outreach copy for each lead
4. Output is ready-to-send marketing messages at scale

## Use Case
Built for small business owners and marketers who need high-volume, 
personalized outreach without the manual workload.
